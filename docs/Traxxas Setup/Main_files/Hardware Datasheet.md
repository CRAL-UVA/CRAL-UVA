# Hardware Datasheet — Base Vehicle

Both Traxxas UDR 01 and UDR 02 are built on the stock **Traxxas Unlimited Desert Racer** chassis (Traxxas model 85086-4). The specifications below are the manufacturer-published stock specifications for that chassis, prior to CRAL modification. See [Integration](Integration.md) for what CRAL changes on top of this base, and [Performance & Capability](Performance.md) for the resulting speed/capability envelope.

## Dimensions & Weight

| | |
|---|---|
| **Length** | 27.32 in (694 mm) |
| **Width** | 13.57 in (345 mm) |
| **Height** | 10.29 in (261 mm) |
| **Wheelbase** | 16.53 in (420 mm) |
| **Track width (front / rear)** | 13.57 in (345 mm) each |
| **Ground clearance (center)** | 2.27 in (58 mm) |
| **Weight (stock, as shipped)** | 13.4 lb (6.1 kg) |

## Tires & Wheels

| | |
|---|---|
| **Tire** | Replica BFGoodrich® KR3 off-road tires |
| **Wheel** | Beadlock-style, 17 mm dual-diameter |

## Gearing & Differentials

| | |
|---|---|
| **Internal gear ratio** | 17.89 : 1 |
| **Gear pitch** | 32 pitch |
| **Front differential** | Sealed 4-gear |
| **Center differential** | Sealed 4-gear (1M weight oil), torque-biasing |
| **Rear differential** | Locked spool |

## Drivetrain & Suspension

| | |
|---|---|
| **Drive configuration** | Shaft-driven 4WD, direct-drive with torque-biasing center drive |
| **Front driveshafts** | Steel CV joints, 6 mm stub axles |
| **Rear driveshaft** | Steel, straight, fixed-length |
| **Front suspension** | Independent double-wishbone, captured rod ends |
| **Rear suspension** | Triangulated 4-link, solid rear axle |
| **Shocks** | 8x aluminum GTR shocks (4 sprung, adjustable ride height), cantilever sway bars F/R |
| **Suspension travel** | 3.15 in front / 4.0 in rear |
| **Chassis** | Composite inverted-tub design with integrated tube frame |

## Stock Electronics (as shipped — superseded on CRAL vehicles)

> These are replaced by the CRAL autonomy stack — see [Integration](Integration.md) and [VESC Setup](../Upper_stack/vesc.md) for what actually runs on the lab vehicles.

| | |
|---|---|
| **Stock motor** | 2200 kV sensorless brushless; 5 mm shaft; 6.5 mm bullet connector; 406 g; 76 mm L x 42 mm dia. |
| **Stock ESC** | Velineon VXL-6s; 6S-rated; integrated cooling fan; Traxxas Link telemetry |
| **Stock radio** | TQi 2.4 GHz, 2-channel; 5-channel micro receiver (model 6533) w/ failsafe + telemetry |
| **Stock steering servo** | 2270 metal-gear digital, high-torque, waterproof |
| **Battery compartment** | 181 x 46 x 56 mm; accepts single 4S LiPo or dual 2S/3S LiPo; Traxxas High-Current connector |
| **Stock rated top speed** | 30+ mph on 4S LiPo, 50+ mph on 6S LiPo |

*Source: manufacturer-published specifications, [traxxas.com/unlimited-desert-racer-85086-4](https://traxxas.com/unlimited-desert-racer-85086-4).*
